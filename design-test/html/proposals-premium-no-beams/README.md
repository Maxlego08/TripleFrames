# Propositions — salles premium sans faisceau

Cette série explore dix compositions de salle de cinéma en conservant trois rangées de quatre fauteuils premium. L'écran reste un élément graphique plat : aucun halo, cône ou faisceau lumineux n'en part.

| Variante | Direction |
| --- | --- |
| A | Gradins sculptés, généreux et courbes |
| B | Allée centrale très lisible |
| C | Double circulation latérale |
| D | Amphithéâtre compact |
| E | Palace art déco feutré |
| F | Studio en bois acoustique |
| G | Black box minimaliste |
| H | Dernier rang sur balcon bas |
| I | Fauteuils-capsules semi-enveloppants |
| J | Rangées ouvertes en éventail |

Chaque fichier HTML est autonome et prévu pour une fenêtre de 1920 × 1080. `contact-sheet.png` permet de comparer les dix directions d'un coup d'œil.
