# Liste d'amorçage TMDB — la voie d'exception, en un geste
# =========================================================
#
# Ce fichier est un COLLAGE, pas du code : il se lit par
#
#     php artisan catalog:import-ids --file=database/data/tmdb-seed-list.txt --dry-run -v
#     php artisan catalog:import-ids --file=database/data/tmdb-seed-list.txt --actor=<e-mail du curateur>
#
# Il entre par la VOIE D'EXCEPTION (§ 9.2, décision 11) : le filtre de goût —
# 500 votes, langue originale dans {fr, en, ja}, sortie depuis 1970 — est
# ignoré entièrement, et chaque film entré par ici est marqué
# `is_import_exception` avec ses motifs, comptables en back-office.
#
# Le filtre de CONTENU, lui, s'applique à l'identique : `adult`, FR -18,
# US NC-17 et US X sont refusés par cette voie exactement comme par le
# balayage (décision 12). Aucune ligne de ce fichier ne le contourne.
#
# Format accepté : un identifiant par ligne, plusieurs par ligne séparés par
# des espaces ou des virgules, une URL `https://www.themoviedb.org/movie/<id>-<slug>`,
# un commentaire après `#`. Les doublons sont retirés au premier passage et
# l'ordre du collage est conservé.
#
# ---------------------------------------------------------------------------
# VÉRIFIER AVANT D'AJOUTER UNE LIGNE, et ce n'est pas une formalité
# ---------------------------------------------------------------------------
#
# Un identifiant TMDB erroné n'échoue pas : il importe SILENCIEUSEMENT un autre
# film, avec ses titres, ses alias et ses clés de réponse. Rien dans la chaîne
# ne le rattrape, et le défaut ne se voit qu'en manche, le jour où le blindtest
# affiche l'image d'un film et attend le titre d'un autre.
#
# Le geste sûr, pour chaque ligne :
#   1. ouvrir la fiche sur themoviedb.org et copier l'URL entière — pas l'id nu ;
#   2. lancer la commande avec `--dry-run -v`, qui affiche le sort de chaque
#      identifiant sans rien écrire ;
#   3. après import, relire la file de curation : c'est là que le titre
#      apparaît, et c'est le dernier filet.
#
# C'est pourquoi ce fichier est livré avec ses SECTIONS et sans identifiants :
# la liste est du contenu de curation, elle se constitue une fiche à la fois,
# et une ligne inventée coûte plus cher qu'une ligne manquante.
#
# ---------------------------------------------------------------------------
# Sections attendues, et pourquoi chacune existe (décision 11)
# ---------------------------------------------------------------------------
